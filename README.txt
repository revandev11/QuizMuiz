LOTUXANA QUIZ

İşə salmaq:
1. Tövsiyə: “Başlat.bat” faylını iki dəfə klikləyin. Sayt yalnız bu kompüterdə, localhost üzərində açılır.
2. Alternativ: index.html faylını Chrome, Edge və ya Firefox-da açın.
3. Ana səhifədə cavab yoxlama üsulunu seçin və “Quizi başlat” düyməsinə basın.

Tətbiq backend, npm və internet tələb etmir. “Başlat.bat” yalnız statik faylları localhost-a təqdim edən kiçik lokal server açır; quiz üçün server tərəfli kod yoxdur. Quizlər, nəticələr, cavablandırılmamış suallar və yadda saxlanmış suallar bu brauzerin localStorage yaddaşında qalır. Brauzerin sayt məlumatlarını təmizləmək tarixçəni silə bilər.

Quiz hər dəfəsində 30 təsadüfi sual və 45 dəqiqə verir. Təkrar quizləri mövcud səhv və ya yadda saxlanmış sualların sayına uyğun qısa ola bilər.

Cavabların ehtimal olunan variantları Excel-dəki 315 sual və “Suallar_ehtimal_olunan_cavablarla.pdf” sənədindən yığılıb. Ehtimal xarakterli cavablar rəsmi cavab açarı deyil; nəticəni mühazirə ilə yoxlayın.
